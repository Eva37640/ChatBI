# ChatBI 智能数据分析助手

## 项目简介

ChatBI 是一个基于自然语言处理的数据分析系统，用户可以通过自然语言提问来查询和分析订单、客户、商品等业务数据。

## 功能特点

- 支持28种查询意图识别
- 自然语言交互界面
- 数据可视化图表生成
- 多表关联查询（订单表、订单明细表、物流信息表）
- 模糊匹配和智能推荐

## 支持的查询类型

### 基础统计查询
- 订单总量、客户数量、商品数量统计
- 按时间范围筛选（今天、昨天、本周、上周、本月、上月等）
- 按客户、仓库、温区分组统计

### 订单分析
- 查询特定订单的详细信息
- 订单进度追踪
- 订单操作记录查询
- 订单处理时长分析

### 商品分析
- 商品销量排名
- 温区商品统计（常温、冷藏、冷冻）
- 商品销量变化趋势

### 客户分析
- 客户订单排名
- 客户订单金额占比
- 客户订单趋势分析

### 物流分析
- 司机工作量统计
- 仓库发货统计
- 物流操作记录分析

### 对比分析
- 月度环比增长
- 时间段对比
- 多维度交叉分析

## 安装说明

### 环境要求
- Python 3.8 或更高版本
- Windows / macOS / Linux

### 安装步骤

1. 确保已安装 Python 3.8+
   ```
   python --version
   ```

2. 安装依赖
   ```
   pip install -r requirements.txt
   ```

3. 将数据文件放入 `data` 文件夹
   - 测试客户下单量1月V2.xlsx
   - 测试客户下单2-3月V2.xlsx

## 运行方式

### 方式一：双击启动脚本
双击运行 `启动.bat` 文件

### 方式二：命令行启动
```
python app.py
```

启动后，在浏览器中访问 http://127.0.0.1:5000

## 技术栈

- **后端**: Flask (Python Web框架)
- **数据处理**: Pandas (数据分析库)
- **可视化**: Matplotlib (图表生成)
- **前端**: HTML5 + CSS3 + JavaScript

## 注意事项

1. 首次运行前请确保 data 文件夹中有正确的 Excel 数据文件
2. 如果端口 5000 被占用，可在 app.py 中修改端口号
3. 建议使用 Chrome 或 Edge 浏览器访问
